# Novedades / Changelog

Una línea por cambio: `- texto en español // English text`. La app muestra la sección de su versión tras
actualizarse, y el workflow *Release* la copia a `update.json` y a la página de la release.

## 0.5.0
- La ventana de ajustes se puede agrandar y maximizar, y recuerda su tamaño // The settings window can be resized and maximized, and remembers its size
- Las descripciones largas pasan a otra línea y, si algo no cabe, se ve entero al pasar el ratón // Long descriptions wrap, and anything that still doesn't fit shows in full on hover
- Nuevos avisos opcionales, desactivados de serie: batería crítica, si no aguanta otro día y para desenchufar al 80 % // New optional alerts, off by default: critical battery, won't last another day, and unplug at 80 %
- El historial guarda un resumen diario para comparar la autonomía mes a mes // The history keeps a daily summary to compare battery life month by month

## 0.4.2
- Autonomía por carga más fiable en dispositivos con lectura aproximada // More reliable battery life per charge on devices with approximate readings
- El tiempo restante aparece mucho antes, a partir de lo aprendido en cargas anteriores // Time left shows up much sooner, based on what was learned from earlier charges
- Las lecturas falsas al encender un dispositivo ya no llegan a los avisos ni al historial // Wrong readings when a device wakes up no longer reach alerts or history
- Los ajustes y el historial ya no se pierden si el PC se apaga mientras se guardan // Settings and history are no longer lost if the PC shuts down while saving

## 0.4.1
- Novedades en el menú del icono de la bandeja y como sección propia en Ajustes, con un punto mientras no las has visto // What's new in the tray icon menu and as its own Settings section, with a dot until you've seen it
- Tras actualizar, los ajustes se abren directamente en Novedades // After an update, the settings open straight on What's new

## 0.4.0
- Instalador: doble clic en el .exe descargado → Instalar, con entrada en Configuración › Aplicaciones // Installer: double-click the downloaded .exe → Install, with an entry in Settings › Apps
- Desinstalar desde Windows o desde Ajustes › General // Uninstall from Windows or from Settings › General
- Versión portable (.zip) que guarda todo junto al .exe // Portable version (.zip) that keeps everything next to the .exe
- Abrir la app cuando ya está en marcha abre sus ajustes // Opening the app while it's running opens its settings
- Si una actualización no arranca bien, se vuelve sola a la versión anterior // If an update fails to start, the previous version comes back on its own
- Versiones de prueba (beta) opcionales en Ajustes › General // Optional test versions (beta) in Settings › General
- Botón "Mi dispositivo no aparece" para reportarlo fácilmente // "My device isn't listed" button to report it easily
- Novedades de cada versión, como esta lista // What's new in each version, like this list
- Nueva página Historial: gráfica de hasta 30 días y autonomía por carga // New History page: up to 30-day chart and battery life per charge
- Instalación silenciosa (--install --silent) y licencia MIT // Silent install (--install --silent) and MIT license
