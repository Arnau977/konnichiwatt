Konnichiwatt portable
=====================

Mientras este archivo esté junto a Konnichiwatt.exe, la app funciona en modo portable:
no se instala, no muestra el instalador y guarda ajustes, historial y registros en la
carpeta "data" de al lado. Se sigue actualizando sola. Borra este archivo para volver
al modo normal.

While this file sits next to Konnichiwatt.exe, the app runs in portable mode: nothing is
installed, the installer isn't shown, and settings, history and logs are kept in the
"data" folder next to it. It still updates itself. Delete this file to go back to normal mode.
